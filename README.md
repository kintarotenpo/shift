# SHIFT BOARD（シフト作成・共有アプリ）

店舗のシフト表をブラウザで作成し、スタッフのスマホへ共有するためのアプリです。
サーバー不要の静的サイトなので、**GitHub Pages で無料公開**できます。

## 公開前の動作確認（このMacで）

1. Finder で **`start.command` をダブルクリック**
   - 初回は「開発元を確認できません」と出ることがあります。その場合は右クリック →「開く」→「開く」
2. ブラウザで `http://localhost:8000` が自動で開きます
3. 終了するときは、起動したターミナルのウィンドウで `Ctrl+C`（またはウィンドウを閉じる）

**スマホでの見え方を確認したいとき**
- 同じWi-Fiにつないだスマホで、ターミナルに表示される `http://192.168.x.x:8000` を開きます
- 閲覧用リンクをスマホで試す場合は、**Mac側も同じ `http://192.168.x.x:8000` で開いてから**「共有」でリンクを作ってください（`localhost` のリンクはスマホでは開けません）
- 初回は macOS から「受信接続を許可しますか？」と聞かれることがあるので「許可」を選んでください

> データはURL（`localhost:8000` / GitHub Pages など）ごとに別々に保存されます。確認中に入力したデータを公開版へ移すときは、**設定 → バックアップを保存** → 公開版で **バックアップを読み込む** を使ってください。

## 公開手順（GitHub Pages）

1. GitHub で新しいリポジトリを作成（例: `shiftboard`、Public）
2. このフォルダの中身をすべてアップロード
   （`index.html` / `css/` / `js/` / `assets/` / `README.md`）
3. リポジトリの **Settings → Pages** で
   Source: `Deploy from a branch` / Branch: `main` / `/ (root)` を選んで Save
4. 1〜2分後に `https://<ユーザー名>.github.io/shiftboard/` で開けます

> 更新したときは、`index.html` 内の `?v=5` の数字を上げるとスタッフのスマホでも確実に最新版が読み込まれます。

## 作成者と閲覧者の分け方

| | 作成者 | 閲覧者（スタッフ） |
|---|---|---|
| 開くURL | 公開URLそのもの | 共有ボタンで作った **閲覧専用リンク**（`…#v=…`） |
| できること | 作成・編集・設定・有給管理・出力・共有 | 月次／日別の閲覧、自分のシフト表示、画像・PDF保存 |
| データ | 作成者の端末のブラウザに保存 | リンク自体にその月のシフトが圧縮して入っている |

- 閲覧専用リンクには編集機能がなく、作成者の端末のデータにもアクセスできません。
- シフトを修正したら、もう一度「共有」を押して新しいリンクを送ってください（古いリンクは古い内容のままです）。
- 作成者のデータは端末ごとに保存されます。PC を替えるときや控えとして、**設定 → バックアップを保存（JSON）** を使ってください。

## 運用の流れ

1. **希望休を入力**：LINE で集めたテキストをそのまま貼り付け
   ```
   平賀　1,4,7,11,14,15,21,22,23,28,29
   酒井　15,23,24有      ← 「有」を付けると有給
   中村　7-8             ← 範囲指定も可
   ```
   判別結果を確認して **「反映して自動作成」**
2. **自動作成**：以下を考慮してシフトを作成します
   - 希望休・有給・固定セルはそのまま
   - スタッフごとの「月の休日数」まで休（自動）を配置
   - 連休・連勤（上限は設定で変更、初期値 5 日まで）をできるだけ避ける
   - メイン店舗に優先配置し、欠員が出た店舗へ「対応店舗」に含まれるスタッフを応援に回す
   - 営業時間の穴が埋まるよう勤務時間をスライド
3. **アラート確認**：人員不足（時間帯つき）と連勤超過を一覧表示。タップで該当日へ移動
4. **アラート自動調整**：休みの入れ替えなどで自動解消を試みます。解消できない分（そもそも人が足りない日など）は手動で調整
   - セルをタップして店舗・時間・休み区分を変更。「固定」にしたセルは自動作成・自動調整で変わりません
5. **共有** → 「LINEで送る」で暫定シフトを連絡
6. 要望があれば修正 → 状態を「確定」にして再度共有

## 機能一覧

- 月次表（スタッフ × 日付、店舗略称・勤務時間、店舗別の人数／必要数）
- 日別表（店舗ごとのタイムライン、30分単位の人数）
- 休みの区分：休(希望)／休(有給)／休(自動)
- 有給管理（付与登録、2年失効・古い付与から消化、残日数、年5日取得義務のチェック）
- CSV 出力／読込（Excel で編集して戻せます。Shift_JIS にも対応）
- PDF／JPG ダウンロード（表示中の月次または日別）
- 共有：LINE／他のアプリ（スマホの共有メニュー）／コピー／画像
- 祝日は自動判定（振替休日・国民の休日を含む）

## ファイル構成

```
index.html
css/style.css
js/util.js       日付・祝日・店舗/スタッフの共通処理・有給計算
js/db.js         データ保存（localStorage）と閲覧リンクの圧縮
js/scheduler.js  自動作成・アラート検出・希望休テキスト解析・CSV
js/views.js      各画面の描画
js/app.js        画面操作・出力・共有
assets/logo.svg  仮ロゴ（差し替え可）
```

ロゴは `assets/logo.svg` を差し替えるだけで全体に反映されます。
